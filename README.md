# Atmosfer Stüdyo

Uyku, kitap okuma ve yolculuk ambiyansları için otomatik video üretici.

## Özellikler
- 🌙 Uyku Ambiyansı (3 saat yağmur, lo-fi müzik)
- 📖 Kitap Okuma Ambiyansı (sayfa sesi, hafif klasik müzik)
- 🚂 Yolculuk Ambiyansı (tren rayı, uzak anons)

## Teknoloji
- Backend: FastAPI (Python)
- Frontend: React
- Kuyruk: Redis + Celery
- Video: FFmpeg
- Yayın: YouTube API
